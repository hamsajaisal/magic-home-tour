🏡 Question Converter

Turn a question paper into question files for Magic Home Tour, and check your question files for mistakes.

How to use (step by step)
  1. Paste the English paper text in the left box and/or the Malayalam paper text in the right box. (Or click "Open PDF / text file".) If you have both versions of the same paper, paste both – questions with the same number are joined together.
  2. Fill in the details below (subject, class, source).
  3. Click Convert. Check every red card – fix the words in the boxes, then tick "I checked this".
  4. Click Download file. Put the file in the game's data/questions folder (see README).
Works best when questions look like "1. Question … (A) … (B) … (C) … (D) …" with "Answer: B" under each question, or an "Answer key" list at the end. Scanned PDFs (photos of pages) cannot be read – type those questions instead.
